PATCH LOG
v0.6 — Arenas & Roster
  • 2 new playable characters: Anchovy Archer 🏹 + Stealth Slice 🥷, each with unique weapon + armor (Tomahawk Anchovy / Sniper's Cloak, Shadow Slice / Phantom Hood)
  • 2 new unlockable arenas: Sundried Slopes 🍂 (autumn boulders) + Frostbite Glacier 🧊 (ice spires) — each progression-gated behind beating the previous on Normal+
  • 2 new tomes implemented: Tome of Echoes 📜 (every Nth projectile duplicates) + Tome of Time ⏳ (slow all enemies when you take damage)
  • Inner-arena obstacles: Sundried gets sandstone boulders, Frostbite gets ice spires — both with real collision for tactical positioning
  • Boost upgrades now cost progressively more slices per level
  • Run-config flow: clicking START RUN now opens a dedicated arena + difficulty picker before the run begins
  • Mobile UI overhaul: 3D char preview replaced with compact selector, landscape layout fits without scrolling, cache-busting on every deploy
  • Dev mode login for testing (About screen → DEV MODE section)
  • Arena scenery tinting now actually works on KayKit GLB trees
  • Distant hills no longer over-bloom into glowing orbs
  • Boss kill on Stage 1 or 2 no longer ends the run as a Stage 3 victory
v0.5 — Character Update
  • 3 new playable characters: Frost Baker, Oven Knight, Crust Runner
  • Each character has a unique weapon + armor exclusive to them
  • Cross-character unlock: reach 1,500 kills with a unique item equipped, then purchase it with Slices
  • 5 new slice-unlockable items: Meatball Minigun, Cheese Whip, Olive Railgun, Mirror Vest, Phoenix Apron
  • Stage progression: defeat the Warlord to advance to Stage 2 → 3, carrying full loadout over
  • Difficulty selector: Easy / Normal / Hard / Extreme with scaled enemy stats and Slice rewards
  • All 7 permanent boosts now active at run start (damage, health, armor, speed, XP, gold, revive)
  • Call the Boss: spend 50 gold from pause menu to summon the final boss immediately
  • Boss ranged attacks fixed — Sauce Slinger, Hammer Chef, and Warlord all fire their specials
  • Stage scaling: Stage 2/3 enemy floors prevent early waves from feeling like a cooldown lap
  • Camera resumes automatically after choosing from chest/level-up screens
v0.4 — Weapons & Visuals
  • KayKit 3D character models for the player and skeleton enemies
  • KayKit weapon models: boomerang → 3D axe, wand orbiting for Thunder Strike, round shield orbital
  • New weapons: Crossbow Bolt (precision pierce), Smoke Bomb (cloud DoT), Bone Staff (skeleton conjurer)
  • Thunder wand cosmetic orbits the player while equipped
  • GPU resource leak fix — all meshes now properly disposed on removal (eliminates pink-screen crash)
v0.3 — Boss System
  • 3-tier boss system: The Sauce Slinger (3:00), The Hammer Chef (6:00), The Warlord (10:00)
  • Boss phase transitions at 50% and 25% HP (Enraged / Desperate)
  • Telegraphed ranged attacks: sauce lobs, cleaver fans, homing shockwaves
  • Boss HP bar, name display, and kill banners
  • Victory screen with run stats
  • Slice meta-currency earned from boss kills, spent in Armory
v0.2 — Core Loop
  • Level-up and chest choice screens with reroll (gold + watch-ad)
  • Armor and Tome systems alongside the weapon pool
  • Armory screen with character, weapon, armor, tome, and boost tabs
  • Synergy upgrades that unlock when prerequisite items are owned
  • Mobile dual-stick floating joystick controls
  • Full mobile browser support: viewport, fullscreen, no scroll
v0.1 — Initial Release
  • Three.js 3D world with procedural rolling terrain and forest ring
  • Pizza Delivery Hero player with animated walk/run/idle cycle
  • 6 enemy types: goblin, bat, brute, skelly, imp, warlord
  • Pizza Toss starter weapon with auto-aim
  • Jump, dash, camera rotate
  • XP gems, gold coins, chest spawns
